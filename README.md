## 概要
discordで通話をしている仲間と、乾杯しましょう！通話中にホームパーティーを開いているような雰囲気を味わうための機能が揃ったツールです。  
通話にいる人だけとのチャット、会話を盛り上げるルーレット、気軽に過ごせるステータス機能などがあります。
